# lassocox_breast_cancer: example dataset for the jsurvival module

Example dataset distributed with the jsurvival jamovi module for
demonstration and testing.

## Usage

``` r
lassocox_breast_cancer
```

## Format

A data frame with 250 rows and 22 variables:

- patient_id:

  character variable

- survival_months:

  numeric variable

- death:

  factor variable

- age:

  numeric variable

- menopausal_status:

  factor variable

- tumor_size_cm:

  numeric variable

- grade:

  factor variable

- stage:

  factor variable

- lymph_nodes_positive:

  numeric variable

- lymph_nodes_examined:

  numeric variable

- er_status:

  factor variable

- pr_status:

  factor variable

- her2_status:

  factor variable

- ki67_percent:

  numeric variable

- histology:

  factor variable

- lvi:

  factor variable

- margin_status:

  factor variable

- surgery_type:

  factor variable

- chemotherapy:

  factor variable

- radiation:

  factor variable

- albumin:

  numeric variable

- hemoglobin:

  numeric variable
