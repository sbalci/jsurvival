# lassocox_lung_cancer: example dataset for the jsurvival module

Example dataset distributed with the jsurvival jamovi module for
demonstration and testing.

## Usage

``` r
lassocox_lung_cancer
```

## Format

A data frame with 200 rows and 15 variables:

- patient_id:

  character variable

- follow_up_months:

  numeric variable

- progression:

  factor variable

- age:

  numeric variable

- gender:

  factor variable

- smoking_status:

  factor variable

- histology:

  factor variable

- stage:

  factor variable

- tumor_size_cm:

  numeric variable

- ecog_performance_status:

  factor variable

- hemoglobin_g_dl:

  numeric variable

- wbc_count_k_ul:

  numeric variable

- platelet_count_k_ul:

  numeric variable

- creatinine_mg_dl:

  numeric variable

- treatment_type:

  factor variable
