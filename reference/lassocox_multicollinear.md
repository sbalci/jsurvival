# lassocox_multicollinear: example dataset for the jsurvival module

Example dataset distributed with the jsurvival jamovi module for
demonstration and testing.

## Usage

``` r
lassocox_multicollinear
```

## Format

A data frame with 180 rows and 15 variables:

- patient_id:

  character variable

- survival_months:

  numeric variable

- death:

  factor variable

- age:

  numeric variable

- sex:

  factor variable

- ecog_ps:

  factor variable

- comorbidity_index:

  integer variable

- crp_mg_l:

  numeric variable

- esr_mm_hr:

  numeric variable

- il6_pg_ml:

  numeric variable

- ferritin_ng_ml:

  numeric variable

- albumin_g_dl:

  numeric variable

- prealbumin_mg_dl:

  numeric variable

- bmi:

  numeric variable

- weight_loss_pct:

  numeric variable
