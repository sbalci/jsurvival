# lassocox_small_cohort: example dataset for the jsurvival module

Example dataset distributed with the jsurvival jamovi module for
demonstration and testing.

## Usage

``` r
lassocox_small_cohort
```

## Format

A data frame with 75 rows and 10 variables:

- id:

  character variable

- time_months:

  numeric variable

- event_occurred:

  factor variable

- age:

  numeric variable

- gender:

  factor variable

- biomarker_a:

  numeric variable

- biomarker_b:

  numeric variable

- biomarker_c:

  numeric variable

- treatment_group:

  factor variable

- severity_score:

  numeric variable
