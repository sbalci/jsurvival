# lassocox_cardiovascular: example dataset for the jsurvival module

Example dataset distributed with the jsurvival jamovi module for
demonstration and testing.

## Usage

``` r
lassocox_cardiovascular
```

## Format

A data frame with 150 rows and 19 variables:

- subject_id:

  character variable

- time_to_event_months:

  numeric variable

- cv_event:

  factor variable

- age_years:

  numeric variable

- gender:

  factor variable

- race_ethnicity:

  factor variable

- bmi_kg_m2:

  numeric variable

- systolic_bp_mmhg:

  numeric variable

- diastolic_bp_mmhg:

  numeric variable

- total_cholesterol_mg_dl:

  numeric variable

- hdl_cholesterol_mg_dl:

  numeric variable

- ldl_cholesterol_mg_dl:

  numeric variable

- diabetes_mellitus:

  factor variable

- hypertension:

  factor variable

- smoking_status:

  factor variable

- family_history_cvd:

  factor variable

- ace_inhibitor_use:

  factor variable

- statin_use:

  factor variable

- aspirin_use:

  factor variable
